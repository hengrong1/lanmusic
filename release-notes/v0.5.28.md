### 修复

- 应用内「检查更新」现在遍历 releases.atom 的全部条目：自动跳过草稿、空壳、资产不可下载的条目，取第一个「版本更高且安装包可下载」的版本。修复了 v0.5.25 因 Windows job 资产被挂到 `untagged-<hash>` tag、旧客户端按 `v{version}` 拼地址必然 404 而永远提示「无更新」的问题
- 安装包下载地址改为按条目**真实 tag** 拼接（不再写死 `v{version}`），避免 CI 资产 tag 与版本号不一致时误判无更新
- CI 做包流程修正：先 `git tag` + 推送保证 tag 就位再触发构建，Windows 装包步骤不再因配置错误中断，从根上杜绝 `untagged-<hash>` 错位 release 再次出现
- 新增 `scripts/fix-github-releases.sh`：一键修复线上资产错位的 Release（开发/运维用）

### 安装说明

- Windows 安装版：下载 LanMusic_0.5.28_x64-setup.exe 双击安装，旧版本可直接覆盖升级（用户数据保留）
- 便携版：下载压缩包解压即用
- 安装包未签名：macOS 首次打开请右键 → 打开（或 `xattr -cr /Applications/LanMusic.app`）；Windows SmartScreen 提示选择「仍要运行」
