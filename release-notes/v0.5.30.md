### 新增
- 歌词搜索命中可直接看到**命中的那一行**：搜索下拉在「艺人 · 专辑」行下方以音符图标带出歌词行，结果页表格在标题下方用弱化色显示，命中关键词高亮，「歌词」徽标悬停也显示具体歌词行。歌词行已自动剥掉 LRC 时间戳与逐字标签、跳过 `[ti:]` 等元信息行，超长句截断加省略号——一眼就能看出为什么搜到这首歌
- 搜索框 / 播放页 / 桌面歌词三处添加快捷按钮，一键跳转设置页对应分区：搜索框齿轮 → 搜索分区，播放页顶栏 Tuning → 音效分区，桌面歌词浮窗控制条齿轮 → 歌词分区。跳转后自动滚动落位并高亮目录，返回一次即离开设置页，不会连环弹出多个设置页

### 优化
- 默认封面（无封面 / 封面加载中）改用主题色渐变，主色跟随系统主题设置；开背景图时深浅两档同配方，不再出现一块亮疤。占位图标色统一下发，浅色 / 深色 / 开背景图三态一致（含托盘菜单的默认封面）
- 播放页顶栏均衡器快捷钮移到右侧，与最小化 / 最大化 / 关闭同组靠右，不再孤悬在左侧
- 桌面歌词描边统一：开启描边后所有行统一走描边层，去掉文字阴影辉光，不再一行描边一行阴影；含连续空格的行描边环不再错位

### 修复
- 淡入淡出下连点暂停 / 播放不再停在暂停态：暂停淡出的 600ms 窗口内音频尚未真正 pause，连点第二下旧逻辑会当成「再暂停一次」。现在会取消挂起的暂停、从已衰减的音量淡回升并停在播放态；点暂停时按钮立即翻转，不再等 pause 事件才有视觉反馈
- 切歌过程中按暂停现在是取消换源并暂停，不再复活旧曲续播
- 后台窗口打断淡入时清理残留动画帧，避免音量停在中间值
- 歌词命中展示改为元数据优先：标题 / 艺人 / 专辑 / 文件名任一命中即以元数据为主（对应文本已高亮），不再顺带返回歌词行；混合结果里只命中歌词的曲目仍带出该行
- 桌面歌词贴边的首字 / 末字描边不再被裁剪：裁剪盒按描边宽度外扩，像素实测首字左缘与末字右缘均完整露出

### 安装说明
- Windows 安装版：下载 LanMusic_0.5.30_x64-setup.exe 双击安装，旧版本可直接覆盖升级（用户数据保留）
- 便携版：下载压缩包解压即用
- 安装包未签名：macOS 首次打开请右键 → 打开（或 `xattr -cr /Applications/LanMusic.app`）；Windows SmartScreen 提示选择「仍要运行」
